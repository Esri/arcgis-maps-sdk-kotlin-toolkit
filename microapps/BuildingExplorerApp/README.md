# Building Explorer Micro-app

This micro-app demonstrates the use of the `BuildingExplorer` toolkit component to browse the levels and sublayers of the building scene layers in a Scene.

![Screenshot](screenshot.png)

## Usage

The application shows a local scene view and a Building Explorer. Once the UI has been populated click on the controls to change what is visible.

For more information on the `BuildingExplorer` component and how it works, see its [Readme](../../toolkit/buildingexplorer/README.md).
